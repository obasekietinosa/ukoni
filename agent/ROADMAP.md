# Ukoni Agent Roadmap

This roadmap outlines the implementation of the natural language interface for Ukoni.

## Phase 0 - Agent Foundation (Current)

- [ ] Project setup & API Client generation
- [ ] Agent Server implementation
- [ ] LLM Provider integration (OpenAI, Gemini)
- [ ] Tool implementation for core features (List Inventory, Create/Add to Shopping List)
- [ ] Basic "Chat" endpoint

## Phase 1 - Expanded Tooling

- [ ] Support for Consumption tracking
- [ ] Support for Transaction history analysis
- [ ] Support for Recipe suggestions (based on inventory)

## Phase 2 - Advanced Context

- [ ] Incorporate recent user activity into context
- [ ] Incorporate household preferences into context
- [ ] Proactive suggestions based on habits

## Phase 3 - Multi-Turn Conversations

- [ ] Persistent conversation history per user session
- [ ] Follow-up questions and clarifications

## Phase 4 - Voice Integration (Future)

- [ ] Speech-to-Text input
- [ ] Text-to-Speech output
